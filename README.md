# Progetto Manga v0.1
PWA mobile-first, local-first.

Funzioni incluse: progetto e note canoniche, reference immagini salvate in IndexedDB, editor pagina base con immagini e balloon trascinabili, preflight locale delle reference, salvataggio pagine, stampa Android per PDF, manifest/service worker PWA.

OpenAI è opzionale e non configurato in questa build. Le reference non vengono inviate automaticamente a servizi esterni.
